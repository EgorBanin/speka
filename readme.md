# Speka — спецификация API для тупых :-)

При унифицированном формате API удобно не описывать всю спеку в каком-нибудь OpenAPI, а бахнуть только самое главное: различающиеся части запросов и ответов, коды ошибок. При этом типы можно вывести из значений, сделав спеку более наглядной. Speka — попытка реализовать эту идею.

```
go install github.com/egorbanin/speka@latest
```

## Примеры использования:

### curl

Это команда предназначена, чтобы вывести `curl` запрос для последующего его использования командой в `shell`.

Подкоманда имеет следующие флаги:

- domain - для указания домена, который будет использоваться. По умолчанию он имеет значение (http://localhost:8080)
- url-path - путь, что идет после домена. Путь должен присутствовать в выбранном файле, иначе выскочит ошибка `urlPath * not found`

```shell
speka --file example/01.json5 curl --url-path /get
```
